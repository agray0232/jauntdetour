Usage guidance

Keep the character intentional.

Do

  • Let orange identify the route and discovery
  • Use teal for primary commands and trust
  • Reserve Fraunces for editorial hierarchy
  • Keep maps and real product states prominent
  • Use one clear primary action per region

Avoid

  • Filling large surfaces with orange
  • Using color as the only state indicator
  • Turning every section into a floating card
  • Using serif type in forms or dense data
  • Adding decorative travel imagery without product context
